# BillMaster on Render - Deployment Guide

## Overview
This guide will help you deploy the complete BillMaster platform to Render, including:
- Backend API (Express.js)
- Frontend (React/Vite) 
- ML Service (FastAPI/Python)
- MongoDB (Render MongoDB)

## Prerequisites
- Render account (free tier available)
- GitHub repository with your code
- Cloudinary account (for file uploads)

---

## Step 1: Update Render Configuration

Update your `render.yaml` file with all services:

```yaml
services:
  # ============ BACKEND SERVICE ============
  - type: web
    name: billmaster-backend
    env: node
    region: ohio
    plan: free
    rootDir: server
    buildCommand: npm install
    startCommand: node server.js
    envVars:
      - key: NODE_ENV
        value: production
      - key: PORT
        value: 10000
      - key: MONGODB_URI
        fromDatabase:
          name: billmaster-db
          property: connectionString
      - key: JWT_SECRET
        generateValue: true
      - key: CLIENT_URL
        sync: false # Will be set after frontend deployment
      - key: CLOUDINARY_CLOUD_NAME
        sync: false
      - key: CLOUDINARY_API_KEY
        sync: false
      - key: CLOUDINARY_API_SECRET
        sync: false
      - key: ML_SERVICE_URL
        value: http://billmaster-ml:8000

  # ============ FRONTEND SERVICE ============
  - type: web
    name: billmaster-frontend
    env: static
    region: ohio
    plan: free
    rootDir: .
    buildCommand: npm install && npm run build
    publishPath: dist
    envVars:
      - key: VITE_API_URL
        sync: false # Will be set after backend deployment
      - key: VITE_WS_URL
        sync: false # Will be set after backend deployment

  # ============ ML SERVICE ============
  - type: web
    name: billmaster-ml
    env: python
    region: ohio
    plan: free
    rootDir: ml-service
    buildCommand: pip install -r requirements.txt
    startCommand: uvicorn main:app --host 0.0.0.0 --port 8000

  # ============ MONGODB DATABASE ============
databases:
  - name: billmaster-db
    plan: free
    databaseName: billmaster
    region: ohio
```

## Step 2: Create Backend .env Example

Create `server/.env.example`:

```env
NODE_ENV=production
PORT=10000
MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/billmaster
JWT_SECRET=your-secret-key-here
CLIENT_URL=https://billmaster-frontend.onrender.com
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret
ML_SERVICE_URL=http://billmaster-ml.onrender.com
```

## Step 5: Deploy Process

### 5.1 Push Code to GitHub
```bash
git add .
git commit -m "Add Render deployment configuration"
git push origin main
```

### 5.2 Deploy to Render
1. Go to [render.com](https://render.com)
2. Click "New +" → "New Blueprint Instance"
3. Connect your GitHub repository
4. Select the `render.yaml` file
5. Click "Apply"

### 5.3 Set Environment Variables in Render Dashboard

After deployment, set these variables in Render dashboard:

**Backend Service (billmaster-backend):**
- `MONGODB_URI`: Automatically linked from database
- `JWT_SECRET`: Auto-generated by Render
- `CLIENT_URL`: Your frontend URL (e.g., `https://billmaster-frontend.onrender.com`)
- `CLOUDINARY_CLOUD_NAME`: Your Cloudinary cloud name
- `CLOUDINARY_API_KEY`: Your Cloudinary API key
- `CLOUDINARY_API_SECRET`: Your Cloudinary API secret
- `ML_SERVICE_URL`: Your ML service URL

**Frontend Service (billmaster-frontend):**
- `VITE_API_URL`: Your backend URL (e.g., `https://billmaster-backend.onrender.com/api`)
- `VITE_WS_URL`: Your backend URL (e.g., `https://billmaster-backend.onrender.com`)

## Common Issues & Solutions

### Issue 1: Database Connection Failed
- Ensure MongoDB is deployed and linked
- Check MONGODB_URI in Render dashboard
- Verify database region matches service region

### Issue 2: Frontend Can't Connect to Backend
- Check CORS settings in backend
- Verify CLIENT_URL is set correctly
- Ensure VITE_API_URL is set in frontend

### Issue 3: WebSocket Connection Failed
- Check WebSocket configuration
- Verify SSL certificate (Render provides free SSL)
- Test WebSocket connection at `/socket.io/` endpoint

### Issue 4: File Uploads Not Working
- Verify Cloudinary credentials
- Check upload directory permissions
- Ensure file size limits are configured

## Production Optimizations

### Enable Caching (Optional)
Add to `render.yaml` for frontend:
```yaml
headers:
  - path: /*
    name: Cache-Control
    value: public, max-age=31536000, immutable
```

### Set Up Custom Domain (Optional)
1. Go to Settings → Custom Domains
2. Add your domain
3. Update DNS settings as instructed

### Monitor Usage
- Check Render Dashboard for resource usage
- Monitor database storage limits
- Set up alerts for quota limits
