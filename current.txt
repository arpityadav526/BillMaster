PROJECT OVERVIEW
-----------------
BillMaster is a full-stack finance management platform featuring:
- ML-powered expense insights and anomaly detection
- Real-time notifications via WebSockets
- Premium dark-first UI with modern design
- Multi-platform support (Web, Flutter mobile app)

TECHNOLOGY STACK
-----------------

FRONTEND (React Web App):
- React 19.2.5 with Vite 8.0.11
- React Router 7.15.0
- Tailwind CSS 4.2.4
- Framer Motion 12.38.0 (animations)
- Lucide React 1.14.0 (icons)
- Recharts 3.8.1 (data visualization)
- Axios 1.16.0 (API client)
- Socket.io Client 4.8.3 (real-time communication)
- Running on: http://localhost:5173

BACKEND (Express.js API):
- Node.js with Express 5.1.0
- Mongoose 8.15.1 (MongoDB ODM)
- Socket.io 4.8.3 (WebSockets)
- JWT authentication (jsonwebtoken 9.0.2)
- Nodemailer 8.0.7 (email notifications)
- Node-cron 4.2.1 (scheduled tasks)
- Helmet 8.1.0 (security)
- Rate limiting and CORS configured
- Running on: http://localhost:5001

ML SERVICE (FastAPI/Python):
- Python with FastAPI (Uvicorn server)
- Pandas and Scikit-learn for data analysis
- Anomaly detection and spending insights
- Running on: http://localhost:8000

MOBILE APP (Flutter):
- Flutter SDK ^3.11.4
- Google Fonts 8.1.0
- FL Chart 1.2.0 (charts)
- Lucide Icons 0.257.0
- Go Router 17.2.3 (navigation)
- Provider 6.1.5+1 (state management)
- Shared Preferences 2.5.5

CURRENT PORT CONFIGURATION

- Frontend (Vite): 5173

PROJECT STRUCTURE
-----------------

ROOT DIRECTORY:
- src/                    - React frontend source code
- server/                 - Express.js backend API
- ml-service/             - Python ML service
- billmaster_app/         - Flutter mobile application
- public/                 - Static assets
- uploads/                - File storage (avatars, CSVs, receipts)

FRONTEND (src/):
- components/
  - layout/               - DashboardLayout, ParticleBackground
  - landing/              - Landing page components
  - ui/                   - Button, Card, Input, Modal, etc.
- context/                - AuthContext, ThemeContext
- pages/                  - DashboardPage, AnalyticsPage, ExpensesPage, etc.
- services/               - API services (api.js, auth.service.js, etc.)
- utils/                  - Utility functions
- App.jsx                 - Main React application
- main.jsx                - Entry point

BACKEND (server/):
- server.js               - Server entry point
- src/
  - app.js                - Express app configuration
  - controllers/          - Route handlers
  - models/               - Mongoose models (User, Expense, etc.)
  - routes/               - API routes (auth, expenses, analytics, users)
  - services/             - Business logic layer
  - middleware/           - Auth, error handling middleware
  - config/               - Database and app configuration
  - jobs/                 - Scheduled tasks and seed data
  - validators/           - Input validation
- uploads/
  - avatars/
  - csv/
  - receipts/
